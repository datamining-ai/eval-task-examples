# Public view — DeepSWE task `deep_rustworkx_simple_gnm`

This folder is the **public view** of one real delivered DeepSWE task. The private parts of the package (hidden contract tests, golden patch, solve script, validation record, repo baseline) are intentionally not published — they are the evaluation assets.

- `instruction.md` — the exact brief the model sees.
- `manifest.md` — task metadata (from `task.toml`) plus package structure.

Difficulty context: under our uniform acceptance budget (GPT-5.6 Sol, xhigh, 4 valid attempts per task), this task family was solved at most twice in four attempts, and 3 of 5 delivered DeepSWE tasks were never solved. See [delivery notes](../../docs/delivery-notes-code.md) and the [Frontier Task Difficulty Report 2026](https://www.datamining.cloud/en/reports/frontier-task-difficulty-2026.html).
